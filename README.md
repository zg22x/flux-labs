# Flux Labs

![Flux Labs](./Flux%20labs/flux_labs.png)

**Flux Labs — We build what moves your business.**

Flux Labs is a modern web and app development agency website designed to showcase digital services through a clean, immersive, and interactive user experience.

The website presents the agency's services, development process, and contact information in a visually engaging interface.

![Website Screenshot](flux-labs/scr/gb.png)

## Purpose of the Project

I built this project to practice:

- Designing modern agency websites.
- Creating immersive and interactive user interfaces.
- Building responsive web experiences.
- Implementing smooth scrolling and scroll-based animations.
- Improving visual storytelling through web design.
- Presenting digital services in a professional way.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- GSAP
- GSAP ScrollTrigger
- Lenis Smooth Scroll
- Google Fonts

## Features

- Modern agency landing page.
- Responsive design for desktop and mobile devices.
- Smooth scrolling experience.
- Scroll-based animations and transitions.
- Interactive visual elements.
- Animated hero section.
- Services showcase.
- Step-by-step development process section.
- Contact call-to-action.
- Minimal and modern visual identity.
